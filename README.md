# TranscriptCGEx + BDFD 2.0

Base inicial para um site de transcripts de tickets.

## Importante
O BDFD 2.0 precisa enviar os dados do transcript para uma API externa.
Este pacote inclui a base do site, mas a integração HTTP com o BDFD precisa ser configurada conforme o método de hospedagem escolhido.

## Iniciar
```bash
npm install
npm start
```

Acesse:
http://localhost:3000
